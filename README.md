## Local Development

To run the backend locally:

1. Navigate to `lib/backend`.
2. Install dependencies: `pip install -r requirements.txt`.
3. Create a `.env` file (copy `.env.example`).
4. Run the app: `python app.py`.

The Flutter app is configured to connect to `http://10.0.2.2:5000` by default (for Android Emulator).
For iOS Simulator or Web, use `http://127.0.0.1:5000` or your local IP.
